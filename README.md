# SEVEN WINTERS V2

An editable 26-page A5 zine with 16 selected photographs.

- `seven-winters-zine-v2-reader.html` — interactive two-page reader with arrow-key navigation
- `seven-winters-zine-v2-overview.html` — overview of every spread
- `case-study.html` — image-led project case study and photobook entry point
- `pages.js` — page content and sequence
- `zine.css` — print and screen art direction
- `sequence.json` — compact editorial map
- `selected/` — copied assets; source files remain untouched
- `output/` — PDF and contact sheet

Open either HTML file directly in Edge or Chrome. In reader mode, click the right page to move forward and the left page to move back. Arrow buttons, keyboard arrows, space, and horizontal swipe are also supported. Page turns use a perspective paper animation. Print the reader file at 100%, with background graphics enabled; the print stylesheet outputs 26 individual A5 pages.
